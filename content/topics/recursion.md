## Теория

<h3>Задача, которая вызывает себя</h3>
<p><b>Рекурсия</b> — это техника, при которой функция решает задачу через вызов самой себя для более простой версии этой же задачи. У любой корректной рекурсивной функции есть <b>базовый случай</b>, возвращающий результат без нового вызова, и <b>рекурсивный шаг</b>, который неизбежно приближает входные данные к базовому случаю.</p>

<h3>Стек вызовов и границы</h3>
<p>Каждый активный вызов занимает кадр стека. В CPython глубина рекурсии ограничена; не повышайте этот лимит как способ исправить алгоритм. Для обработки длинных последовательностей и обхода глубоких структур чаще выбирайте цикл или явный стек. Рекурсия хороша, когда структура данных естественно вложена: дерево, каталог или выражение.</p>

<h3>Стоимость вычислений</h3>
<p>Наивный рекурсивный Fibonacci многократно вычисляет одни и те же значения. <code>functools.cache</code> хранит результаты уже вычисленных аргументов, но применим только к хешируемым входным данным и увеличивает занимаемую кэшем память. Сначала выбирайте ясный алгоритм, затем измеряйте и оптимизируйте его при необходимости.</p>

## Примеры кода

### Факториал: базовый случай и рекурсивный шаг

Аргумент уменьшается на единицу, пока не достигнет нуля.

```python
def factorial(number: int) -> int:
    if number < 0:
        raise ValueError("Факториал определён только для неотрицательных чисел")
    if number in (0, 1):
        return 1
    return number * factorial(number - 1)

print(factorial(5))
```

### Обход вложенных данных

Рекурсия естественно проходит элементы, которые сами могут быть списками.

```python
def flatten(items: list[object]) -> list[object]:
    result: list[object] = []
    for item in items:
        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)
    return result

nested = [1, [2, [3, 4]], 5]
print(flatten(nested))
```

### Fibonacci с кешированием

Кеш сохраняет результат для каждого уже встреченного аргумента.

```python
from functools import cache

@cache
def fibonacci(index: int) -> int:
    if index < 0:
        raise ValueError("Индекс не может быть отрицательным")
    if index < 2:
        return index
    return fibonacci(index - 1) + fibonacci(index - 2)

print(fibonacci(40))
print(fibonacci.cache_info())
```

### Когда цикл лучше рекурсии

Линейное суммирование не требует дополнительных кадров стека.

```python
def sum_with_loop(numbers: list[int]) -> int:
    total = 0
    for number in numbers:
        total += number
    return total

print(sum_with_loop(list(range(1, 11))))
```
