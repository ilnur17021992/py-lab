## Теория

<h3>Состояние и сравнения</h3>
<p>Значение аргумента по умолчанию вычисляется один раз при определении функции, поэтому список или словарь станет общим состоянием вызовов. Используйте <code>None</code> и создавайте коллекцию внутри. Оператор <code>==</code> сравнивает значения, а <code>is</code> — один ли это объект; обычно <code>is</code> уместен для <code>None</code>.</p>

<h3>Предсказуемое выполнение</h3>
<p>Удаление элементов из списка во время обхода может пропустить значения из-за сдвига индексов. Постройте новый список или обходите копию. <code>except:</code> перехватывает в том числе системные исключения; ловите конкретный тип. Файлы открывайте через <code>with</code>, секреты получайте из безопасной конфигурации, а пограничные случаи закрепляйте тестами.</p>

## Примеры кода

### Изменяемый аргумент по умолчанию

Новый список создаётся для каждого вызова, если вызывающий код не передал свой.

```python
def append_item(item: str, items: list[str] | None = None) -> list[str]:
    if items is None:
        items = []
    items.append(item)
    return items

print(append_item("A"))
print(append_item("B"))
print(None is None, [1] == [1], [1] is [1])
```

### Фильтрация без изменения обходного списка

Включение формирует новый результат, сохраняя исходные данные неизменными.

```python
numbers = [1, 2, 3, 4, 5, 6]
odd_numbers = [number for number in numbers if number % 2]

try:
    divisor = 0
    result = 10 / divisor
except ZeroDivisionError:
    result = None

print(numbers, odd_numbers, result)
```

### Настройки и граничные случаи

Секрет не хранится в исходном коде: приложение получает его из окружения и явно проверяет обязательное значение.

```python
import os


def load_page(page: int, page_size: int) -> tuple[int, int]:
    if page < 1 or not 1 <= page_size <= 100:
        raise ValueError("Некорректные границы страницы")
    return page, page_size

api_token = os.getenv("APP_API_TOKEN")
print("Токен настроен:", api_token is not None)
print(load_page(1, 20))
```
